# BiliLab · AI 账号观测台

一个只跑在本机的 B 站「AI 运营账号」观测工具：定时抓取关注分组里的账号，把每次结果存成独立快照，然后算出播放趋势、互动率、发布时刻分布、账号存活率等指标，用一个网页看板展示。

> 2026 年 10 月，B 站出现了一批「AI 接管 B 站账号」的内容（`Day 0`、`大肥鱼`、`鲸鱼娘`……）。这个工具原本是为了跟踪这个现象而写的，但它对任何关注分组都适用。

---

## 它做什么

- **扫码或粘贴 Cookie 登录**，Cookie 用 Windows DPAPI 加密后存本地，不上传任何地方
- **按关注分组抓取**：每个账号取最近 N 条视频，带播放、点赞、投币、收藏、评论、弹幕、分享
- **快照式存储**：每次抓取写入新文件，永不覆盖；分析靠相邻快照做差
- **每天多个闹铃**：默认 00:00 / 08:00 / 15:00，自动静默抓取
- **看板**：播放排行、发布时间分布、时长分布、粉丝/播放关系、留存曲线、趋势对比
- **导出**：JSON / CSV，可直接喂给 pandas

## 环境要求

- Windows 10 / 11（Cookie 加密依赖 DPAPI，开机自启依赖注册表）
- Python **3.9+**
- **不需要**安装任何第三方库，全部用标准库

## 快速开始

```bat
git clone <this repo> bililab
cd bililab
start.bat
```

浏览器会自动打开 <http://127.0.0.1:8765>。

第一次启动会在项目根目录生成 `config.json`（已被 `.gitignore` 忽略）。

### 1. 登录

两种方式，任选其一：

- **扫码**：看板「登录」页，用 B 站 App 扫码
- **粘贴 Cookie**：从浏览器开发者工具复制整行 Cookie（至少含 `SESSDATA`），粘进输入框

> Cookie 只会加密保存在本机 `config.json` 的 `cookies_enc` 字段，脚本本身不联网上传。

### 2. 选择分组并抓取

- 「抓取」页选分组（默认会列出你所有关注分组，可多选）
- 选每个账号抓多少条（20 / 50 / 100）
- 选抓取速度（建议默认 8 次/秒，别调高）

### 3. 设置自动记录

在「抓取 → 自动记录」里加闹铃，比如 `00:00`、`08:00`、`15:00`。

规则：

- 每个时刻**每天只跑一次**，记录在 `config.json` 的 `last_runs`
- 错过超过 **90 分钟**就标记为「已错过」，当天不补
- 机器睡眠/关机时不会执行——需要唤醒定时器或保持不休眠

## 目录结构

```
bililab/
├── server.py             # HTTP 服务 + 路由
├── core/
│   ├── auth.py           # 登录 / Cookie 加密存储
│   ├── bili.py           # B 站接口封装（wbi 签名、限速、重试）
│   ├── crawl.py          # 抓取调度、快照读写
│   ├── analyze.py        # 指标计算
│   └── auto.py           # 闹铃调度 + 开机自启
├── static/               # 前端（原生 JS + ECharts，全部本地加载）
├── data/snapshots/       # 快照输出目录（不入库）
└── start.bat
```

## 已知限制

- **每号只保留最近 N 条**，超出部分不抓，所以「总播放」是下界，「首条投稿时间」可能偏晚
- B 站接口有风控：请求过快会返回 `-352` / `-799` / HTTP `412`，本项目内置令牌桶、拆分限速（空间接口单独限速）、熔断与退避，但**仍然建议 ≤10 次/秒**
- 视频列表接口需要 wbi 签名，签名密钥会缓存在 `data/wbi.json`
- 只做本地单人使用：没有账号体系，不要暴露到公网
